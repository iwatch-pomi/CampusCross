# Campus-Cross 打ち出し方・コピー集

> 人集めの言葉と、サービス内の文言をそろえるための資料です。
> 画面に出す文言の実体は `lib/content.ts` にあり、そこを書き換えると画面にも反映されます。

## 基本の方針：「寄り添う」

| 決めごと | 理由 |
|---|---|
| 不安を**あおらず、寄り添う**。「ガクチカがないとヤバい」ではなく「ガクチカがない、と思っている人ほど、話せることがある」 | あおる言い方はSNSで反発を受けやすい。内定目的だけの人が増えると、直前キャンセルや無断欠席も増える |
| 「ガクチカになる」と**言い切らない**。約束するのは「続けると語れる経験」と「残る記録（教えた回数・テーマ・お礼コメント）」 | 15分を1回だけでは、面接で語れるエピソードになりにくい。期待を上げすぎると評判を落とす |
| ガクチカの訴求は、とくに**教える側**に向ける | サービスで不足しやすいのは教える人。「専門外の人に説明した経験」の方がガクチカとしても強い |
| 宣伝では「**出会い**」「**つながり**」を使わず、「**学び**」「**専門**」で統一する | 出会い目的の人を呼び込まないため（安全・防犯の方針と一貫させる）。禁止事項の説明の中では使ってよい |

## 採用したコピー

### 共通
- 「ガクチカがない、と思っている人ほど、話せることがある。」
- 「ガクチカ、今からでも間に合う。いま学んでいることを話すだけ。」

### 教える人へ
- 「あなたの専門、15分で誰かの“初めて知った”になる。」
- 「研究を専門外の人に説明できる人は、面接で強い。」
- 「研究じゃなくても大丈夫。授業・ゼミで学んでいることで。」

### 学ぶ人へ
- 「他学部を5つ語れる就活生になろう。1回15分。」
- 「面接官の専攻の話、ちょっと分かると強い。」

## 画面のどこに何が出ているか

| 画面 | 文言 | `lib/content.ts` の定義 |
|---|---|---|
| 紹介ページ・ヒーロー | 「いま学んでいることを話すだけで、誰かの『初めて知った』になります」 | `HERO.sub` |
| 紹介ページ・「FOR 就活」 | 見出し「ガクチカがない、と思っている人ほど。」、教える人へ／学ぶ人への2列、注意書き | `GAKUCHIKA` |
| 紹介ページ・登録フォームの上 | 「ガクチカ、今からでも間に合う。」「いま学んでいることを話すだけ。…」 | `SIGNUP_CTA` |
| プロフィール登録（初回） | 「ガクチカがない、と思っている人ほど、話せることがあります。…」 | `ENCOURAGE.onboarding` |
| プロフィールの自己紹介欄のヒント | 「授業やゼミで学んでいることなど」 | `ENCOURAGE.bioHint` |
| カード作成 | 「研究じゃなくても大丈夫。…続けると、教えた回数とお礼コメントが記録に残ります。」 | `ENCOURAGE.offerNew` |
| マイページ・教えた実績 | 「エントリーシートや面接で話せる記録になります」 | `ENCOURAGE.teachingRecord` |

## SNS投稿の文案

**X（教える側向け）**
```text
ガクチカが「ない」と思ってる人へ。
授業・ゼミ・研究で学んでることを、他学部の人に15分話すだけで、
「専門外の人に説明した経験」が積み上がっていきます。
回数・テーマ・相手からのお礼コメントが記録に残るので、ESのネタにも。
広大生限定・無料。Campus-Cross（リンク）
```

**Instagram ストーリーズ（学ぶ側向け）**
```text
1枚目：「他学部の研究、説明できる？」
2枚目：「15分で1学部。学内のカフェや図書館で、専門の人から直接聞ける」
3枚目：「広大生限定・無料・大学メールで30秒登録」
```

## 広げ方の順番

1. **教える人を先に10〜15人集める**（ゼミ・研究室の先輩や友人に直接声をかけ、カードを出してもらう）。カードが並んでいない状態で告知しない
2. **時期**：冬のインターン選考・本選考のエントリーシートの時期（11〜2月）が、ガクチカへの関心が最も高い
3. **学内の経路**：サークル・ゼミの LINE グループ、学内の掲示（許可が必要か確認）、学内起業支援センター経由の告知
4. **口コミ**：お礼コメントを本人の同意のうえで SNS にシェアできる機能（未実装）
