# Campus-Cross（キャンパス・クロス）

> 15分で、となりの学部へ。

学内メール認証にもとづき、学生同士が他学部の専門・研究・スキルを15〜30分で気軽に教え合う、お金をやり取りしない「ギブ＆テイク型」の異分野ナレッジ交換プラットフォームです。

- 教えると **+1枚**、教わると **−1枚**（チケット）
- 登録時に **3枚**、毎月 **1枚** を配布（残高5枚未満の人のみ）
- 教える側が **オフィスアワーの枠** を出し、学ぶ側がワンクリックで予約する
- 学内での **対面** を推す
